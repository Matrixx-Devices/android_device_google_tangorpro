The Pixel Tablet (codenamed _"tangorpro"_) is Google's first gen Tensor G2 Premium tablet.
Pixel Tablet was announced on 2023, May 10 and then released on Released 2023, June 20.

## Device specifications
| Device       | Google Pixel Tablet                               |
| -----------: | :--------------------------------------------------                             
| SoC          | Google Tensor G2 (5 nm)                                                         |
| CPU          | Octa-core (2x2.85 GHz Cortex-X1 & 2x2.35 GHz Cortex-A78 & 4x1.80 GHz Cortex-A55)|
| GPU          | Mali-G710 MP7                                                                   |
| Storage & Ram| 128GB 8GB RAM, 256GB 8GB RAM UFS 3.1                                            |
| Shipped Android version |Android 13, upgradable to Android 15, up to 5 major Android upgrades  |
| Battery      | Li-Po 7020 mAh (27 Wh), non-removable                                           |
| Dimensions   | 258 x 169 x 8.1 mm (10.16 x 6.65 x 0.32 in)                                     |
| Display      | 1600 x 2560 pixels, 16:10 ratio (~276 ppi density)                              |
| Rear camera  | 8 MP, f/2.0, 24mm (wide), 1/4.0", 1.12µm, HDR, panorama, 1080p@30fps            |
| Front camera | 8 MP, f/2.0, 24mm (wide), 1/4.0", 1.12µm, HDR, panorama, 1080p@30fps            |
